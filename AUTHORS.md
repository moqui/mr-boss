## Contributing

We accept code only from people who have signed this file. To sign it, add a line to both lists below, the one
under the Copyright Waiver and the one under the Grant of Patent License:

```
- Written in <years> by <legal name> - <GitHub username>
```

Make that commit from the GitHub account that submits your pull requests. A pull request with only that commit is
best, or it can be the first commit of your first pull request. Each mr-* repository has its own AUTHORS.md: sign it
in each repository you contribute to. The statements cover "any and all copyright interest in this software", so a
signature added later covers your earlier commits too.

We do not merge code from an account that has not signed. We may still take the ideas from such a pull request, but
not its code: the change is written again, with AI assistance as most of MR Moqui is, and the pull request is closed
without being merged.

Your signature covers everything you submit, whatever tools you used. AI tools are tools used by people (see the
[AI/LLM Policy](https://github.com/moqui/mr-moqui#aillm-policy)); they do not sign this file. The person who uses them and submits the work signs it, and
is responsible for that work as for code they typed.

For what to put in an issue or a pull request see the
[Issue and Pull Request Guide](https://moqui.org/m/docs/moqui/Issue+and+Pull+Request+Guide). Report security issues
privately, as [SECURITY.md](https://github.com/moqui/mr-moqui/blob/master/SECURITY.md) says.
